# HeadDistanceTravelled
HMDの移動距離を記録します。  
手の移動距離（左右それぞれ）も記録します。  
手の距離は左右それぞれ個別のフローティングスクリーンに表示され、スクリーンは頭ではなく手（トラッキングされている手の位置）を起点にします。  
  
ゲーム中に移動距離を頭上に表示するオプションがあります。  
表示したくない場合は「ShowDistanceOnHMD」をfalseにしてください。  
この設定はゲーム内からでも切り替えることができます。  

手の移動距離を表示したくない場合は「ShowHandDistance」をfalseにしてください。  
メニューのメインビューには左右の手の累計移動距離が表示されます（ハンドトラッキングが切れている場合、手のスクリーンには何も表示されません）。
